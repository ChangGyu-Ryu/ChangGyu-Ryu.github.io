# 류창규 포트폴리오

이력서에 요약된 Java·Spring 프로젝트와 AI 협업 프로젝트를 기획, 구현 범위, 검증 근거로 정리한 엔지니어링 포트폴리오입니다.

- Website: [changgyu-ryu.github.io](https://changgyu-ryu.github.io/)
- Structure: static HTML, CSS, JavaScript
- `index.html`: 업무 프로젝트 기록
- `ai-projects.html`: AI 협업 프로젝트 기록

## 로컬 미리보기

```bash
python3 -m http.server 4000
```

브라우저에서 `http://localhost:4000`을 엽니다.

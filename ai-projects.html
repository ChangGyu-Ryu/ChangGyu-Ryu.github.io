00 / COLLABORATION MODEL

사람의 판단과 AI의 실행 범위를 나눴습니다.

  1. 01

    문제와 완료 기준은 직접 정의했습니다.

    실제 사용 맥락, 필요한 기능, 공개 범위와 품질 기준을 먼저 정했습니다.

  2. 02

    AI의 역할과 결과물 기준을 구체화했습니다.

    조사·구현·검증 역할을 나누고, 문서·코드·테스트·리뷰 자료의 형식과 완료 조건을 정했습니다.

  3. 03

    실제 데이터와 테스트로 다시 확인했습니다.

    AI가 만든 결과를 그대로 채택하지 않고, 브라우저 확인·테스트·파일 검증과 사용자 피드백을 거쳐 보정했습니다.

01—05 / AI BUILD RECORDS

기획과 구현을 분리해 기록한 다섯 가지 사례

01

WORKFLOW PROTOTYPE

Xiaomi Reels Factory

GPT·Codex · Playwright · ffmpeg

제품 근거 조사부터 세로 영상 렌더·QA까지 연결한 제작 팩토리

PROJECT INTENT

제품별 릴스 제작을 반복 가능한 공정으로 만들고, 홍보 문구의 공식 근거와 외부 영상 소스의 사용 조건을 결과물까지 추적할 수 있도록 기획했습니다.

PLANNED FEATURES

  • 근거 조사·콘텐츠 방향·자막·자산·레이아웃·렌더·QA를 9개 역할로 분리
  • 주장과 출처를 ID로 연결하는 claim/source 기록
  • v1~v6 콘텐츠 방향 비교와 모바일 안전 영역 검증
  • Playwright·ffmpeg 렌더와 Drive 해시 확인

IMPLEMENTED FEATURES

  • 제품 작업 폴더·brief·run state·캘린더·runbook을 만드는 CLI
  • 필수 CSV 스키마, 경로 안전성, 덮어쓰기 방지와 큐 upsert
  • 1080×1920·30fps·14~16초 MP4와 contact sheet 자동 생성
  • 8개 제품 폴더 구성, 4개 제품의 v1~v6 verifier 통과

AI COLLABORATION

GPT·Codex를 단순 문구 생성기가 아니라 역할별 제작 에이전트로 사용하고, CSV·Markdown·run-state 계약으로 산출물을 연결했습니다. 현재 상태는 AI 협업형 반자동 프로토타입이며 앱 내부 LLM이나 자동 게시 기능은 포함하지 않습니다.

VERIFIED SCOPE 폴더 구조 · 영상 규격 · CSV 형식 · 렌더 산출물 · 해시

02

PRIVATE PREVIEW

Hero Town Wiki

Unity data · Static web · Cloudflare

게임 데이터를 추출·조인해 만든 한국어 도감과 조합 실험 위키

PROJECT INTENT

Unity IL2CPP 게임 설치 데이터에서 한국어 이름·스킬·이미지 자산을 재현 가능한 방식으로 추출하고, 검색과 조합 비교가 가능한 팬 위키로 구성하려고 했습니다.

PLANNED FEATURES

  • 용사·코스튬·몬스터·무기·재료를 아우르는 한국어 도감
  • 검색·정렬·필터와 카드·상세 화면
  • 추천 조합과 3인 커스텀 비교 실험실
  • 게임 에셋 기반 테마 배경과 세계관·패치 정보

IMPLEMENTED FEATURES

  • 용사 330·코스튬 108·몬스터 150·무기 246·재료 29 분류
  • 데이터 조인, 검색·필터, 상세·라이트박스와 전용 무기 연결
  • 436개 스킬 연구 노드와 3슬롯 조합 비교
  • 5종 테마 배경, 전용 에셋 렌더러와 관련 테스트 24개 통과

AI COLLABORATION

제품 방향과 데이터 정확성 기준은 직접 정하고, GPT·Codex가 번들·IL2CPP 구조 조사, 추출·조인 스크립트, 프론트 구현, 브라우저 QA와 테스트를 수행했습니다. 결과는 인증과 검색 차단이 적용된 비공개 프리뷰로 운영했습니다.

BOUNDARY 비공식 팬 프로젝트 · 공개 서비스 및 공식 제휴로 표현하지 않음

03

LOCAL macOS APP

Upbit Market Journal

Swift · WebSocket · Agent workflow

실시간 시장 상태와 판단 기록·사후 복기를 연결한 macOS 도구

PROJECT INTENT

가격을 예측하거나 거래를 자동화하기보다, 시장을 볼 때 어떤 근거로 판단했는지 남기고 일정 기간 뒤 틀린 이유와 놓친 신호를 복기하도록 기획했습니다.

PLANNED FEATURES

  • BTC·ETH·USDT의 원화 시세와 live/stale 상태
  • 뉴스·거시 맥락을 결합한 일일 스냅샷
  • 판단 기록, 7일 후 리뷰와 반복 오류 분석
  • 역할별 AI 에이전트와 사용자 승인 경계

IMPLEMENTED FEATURES

  • Upbit WebSocket·CoinGecko 데이터 결합과 재연결 처리
  • RSS 수집, Markdown 스냅샷과 메타데이터 파싱
  • 판단·리뷰·실수 태그·학습 내용을 저장하는 CLI와 보고서
  • Agent Briefing·Council Packet·제안 결정 이력과 검증 도구

AI COLLABORATION

Orchestrator·Market Data·Research·Journal·QA·Risk 역할과 승인 정책을 설계했습니다. 에이전트가 동일한 런타임 상태와 보고서를 읽도록 만들었지만, 완전 자율 LLM이 아니라 파일·CLI 기반 council과 사용자 승인 워크플로입니다.

NOT INCLUDED 자동매매 · 매수·매도 추천 · 수익 예측

04

DEPLOYED WEB APP

Retail Ops Console

Next.js · Supabase · Cloudflare

현업 지식을 매출 정산·보고·재고·일정 기능으로 구조화한 운영 콘솔

PROJECT INTENT

매장 오픈·마감 보고, 온·오프라인 매출 차액, 제품·재고 정보와 월간 근무 일정을 여러 파일과 메시지에서 찾던 업무를 하나의 관리자 웹서비스로 통합하려고 했습니다.

PLANNED FEATURES

  • 채널별 매출 정산과 차액 근거·미해소 항목 관리
  • 카카오톡 보고 파싱과 오픈·마감 보고서 생성
  • 제품 지식·재고번호 검색과 판매 시나리오
  • 근무표 인식, 수동 보정과 Google Calendar 동기화

IMPLEMENTED FEATURES

  • ERP 조정·취소·환불을 반영한 정산 계산과 보고서
  • 다중 행 메시지 파싱·태깅·중복 제거와 원본 보관
  • 제품 카탈로그, Markdown 재고 파싱·SKU 매칭
  • Local/Supabase 저장소, 관리자 인증·RLS와 Cloudflare 배포

AI COLLABORATION

실제 업무 규칙과 예외 조건은 직접 설명하고 검수했으며, Codex가 이를 설계 문서·도메인 로직·테스트·관리자 화면·배포 구성으로 전환했습니다. 앱 내부 생성형 AI가 아니라 현업 지식을 AI와 함께 소프트웨어로 구조화한 사례입니다.

VERIFICATION 도메인 테스트 · lint · 인증/RLS · 배포 응답

05

PUBLIC WEB DEMO

GreenPutt Prototype

Vanilla web · Canvas 2D · AI image workflow

최종 제품 사진과 자체 커머스가 준비되기 전에도 브랜드 가치를 설명하는 인터랙티브 웹

PROJECT INTENT

프로토타입 단계의 퍼팅 브랜드가 핵심 가치인 ‘Zero Head-Up’을 설명하고, 판매 가능한 Polvert 상품은 기존 Imweb 스토어로 연결하도록 브랜드 경험과 커머스의 역할을 구분해 설계했습니다.

PLANNED FEATURES

  • 캠페인형 홈과 Zero Head-Up 제품 스토리
  • 제품 준비 상태에 따라 달라지는 CTA
  • Imweb 구매 브리지와 문의·지원 흐름
  • 향후 Imweb 콘텐츠 블록으로 이전 가능한 모듈형 구조

IMPLEMENTED FEATURES

  • 포인터에 반응하는 퍼팅 거리·궤적·컵인 Canvas 2D 연출
  • 4단계 메커니즘 데모와 자동·수동 제품 캐러셀
  • 반응형 레이아웃, SEO·공유 메타와 Imweb 링크
  • GitHub Pages 공개 데모 배포와 데스크톱·모바일 반복 브라우저 QA

AI COLLABORATION

PM·브랜드·카피·이미지·프론트엔드·QA·보안 역할과 승인 기준을 나누어 AI 협업 프로세스를 운영했습니다. AI 이미지가 로고를 왜곡하는 문제는 빈 패치 생성 후 실제 로고를 표면 각도에 맞춰 합성하고 축 정렬 검수 이미지를 남기는 방식으로 보정했습니다.

NOT INCLUDED 자체 결제·회원·주문·문의 폼 · 실제 하드웨어 연동

도요타 HR 시스템

㈜애자일 · 2025.02

권한에 따라 달라지는 HR 캘린더

SITUATION

근태·시간외근무·휴가를 캘린더에서 한눈에 확인하되, 팀장과 일반 사용자에게 서로 다른 조회 범위를 제공해야 했습니다.

MY ROLE

㈜애자일 웹 개발자로 캘린더의 화면·서버·DB 기능 개발과 테스트를 맡았습니다.

IMPLEMENTATION

JSP·JavaScript·jQuery 화면과 Spring Boot Controller·Service, JPA·Oracle 조회 로직을 연결했습니다. 기존 SQL과 프로시저를 분석해 필요한 부분도 수정했습니다.

VERIFICATION

팀장은 팀원의 현황까지, 일반 사용자는 본인의 정보만 조회하도록 권한별 동작을 구현하고 기능 테스트로 확인했습니다.

STACK JSP · jQuery · Spring Boot · JPA · Oracle · SQL

02

PROJECT

차세대 사회보장정보시스템

㈜브이티더블유 · 2020.10–2023.11

구축한 기능이 운영에서 안정될 때까지

SITUATION

차세대 사회보장정보시스템의 구축과 개통 이후 유지보수를 함께 경험했습니다. 2022년 9월 개통 직후 임대주택 파트에는 하루 10~15건의 SR이 들어왔습니다.

MY ROLE

분석·설계 단계의 프로그램 설계서와 화면 정의서 작성부터 화면·서버·SQL 개발, 통합테스트와 개통 후 결함 조치까지 수행했습니다.

IMPLEMENTATION

eXbuilder6 화면과 Java·Spring 서버 로직, SQL을 개발했습니다. 이후 국가보훈부·임대주택 관련 SR 약 300건, 상수도요금 배치와 일부 운영 배치 리팩터링, Code-Ray 취약점 150여 건과 개인정보 마스킹을 처리했습니다.

OBSERVED RESULT

운영 반영 전에 현업과 반복해서 결과를 확인했고, 2022년 12월에는 임대주택 파트의 일일 SR이 1~2건 수준으로 줄었습니다.

STACK Java · Spring Framework · eXbuilder6 · Spring Batch · Oracle · Code-Ray

03

PROJECT

디지털서비스플랫폼 개방지원

㈜브이티더블유 · 2023.12–2024.06

기존 서비스에서 45종 API의 기준을 찾다

SITUATION

현장 개발 환경과 기존 서비스를 먼저 파악한 뒤, 병역판정검사 신청 43종과 예비군 동원훈련 2종을 플랫폼 표준에 맞춰 개발해야 했습니다.

MY ROLE

2인 팀의 파트 리드와 개발을 병행했습니다. 개발 범위를 정리하면서 실제 API 코드와 테스트, 인터페이스 정의서 작성에도 직접 참여했습니다.

IMPLEMENTATION

IP·방화벽·DB·SVN과 개발도구 환경을 구성하고 기존 GET 요청·응답과 업무 로직을 확인했습니다. 이후 POST 방식 코드와 JSON 요청·응답 구조, CI·성명 기반 병적정보 연계 로직과 암복호화 모듈을 적용했습니다.

VERIFICATION

테스트 요청으로 POST 응답과 암복호화 동작을 확인했습니다. 45종 API의 요청·응답 항목과 샘플 데이터를 인터페이스 정의서에 정리해 코드와 검증 기준을 함께 남겼습니다.

STACK Java · Spring Framework · REST API · JSON · Oracle · 암복호화
